# 中飛車道場 説明書

Oct 8, 2026 · @としき

中飛車道場は、中飛車の定跡を自分で指して身につける将棋学習ツールです。22通りの変化を中盤まで収録し、全324局面にAI（やねうら王＋水匠5）の評価値が付いています。

## ファイル構成

ふだん使うのはスマホ版です。どちらもブラウザで開くだけで動き、インストールは不要です。

| ファイル | 向いている使い方 | 稽古 | 腕試し | 振返り |
| --- | --- | --- | --- | --- |
| nakabisha\_sp.html（スマホ版） | 1画面に収まり、スクロールせずに操作できる | ○ | ○ | ○ |
| nakabisha.html（PC版） | 広い画面で、解説と候補手を並べて読める | ○ | × | × |

クリア記録はそれぞれの端末のブラウザに保存されます。別の端末やブラウザとは共有されません。

## 画面の見方（スマホ版）

画面は上から5つの部分に分かれています。

| 場所 | できること |
| --- | --- |
| 見出し | 「稽古｜腕試し｜振返り」の切り替え、定跡の選択、≡（メニュー） |
| 評価値バー | 今の局面のAI評価値と形勢（互角・先手有利など） |
| 盤と駒台 | 駒をタップしてから移動先をタップして指す。持ち駒は駒台の駒をタップしてから打つ場所をタップ |
| 説明エリア | 正解・不正解、手の意味、相手の手の解説。長いときは指でスクロール |
| 操作バー | ヒント・答え・戻る・解説・最初から |

「解説」を押すと、下からシートが開きます。シートには「解説」（全文、他の候補手とその不都合、AIの候補手）「棋譜」「心得」「設定」「読込」のタブがあります。

## 稽古モード

定跡を一手ずつ、自分で指して覚えるモードです。相手の手は自動で返ってきます。

1. 画面上の選択欄で定跡を選ぶ（先手中飛車／ゴキゲン中飛車／5筋の歩交換）。
2. 中飛車側の手を指す。正解すると、その手の意味とAI評価値が出る。
3. 相手は少し考えてから指す。動かす駒が赤く光り、行き先が点線で示されたあと、駒が動く。
4. 相手の応手が分かれる局面では、説明エリアに選択ボタンが並ぶ。学びたい変化を選ぶ。
5. 変化の最後まで指すと「クリア」。まだ指していない変化の数も表示される。

定跡と違う手を指したときの判定は次のとおりです。

| 指した手 | 表示 | ミスに数えるか |
| --- | --- | --- |
| 定跡の手 | 正解と、その手の意味 | 数えない |
| 定跡手との評価値の差が50点以内 | 「評価値で見て遜色なし」 | 数えない |
| それより悪い手 | 不都合の説明、評価値の差、AIの読み筋 | 数える |
| 反則手（二歩・王手放置など） | 指せない理由 | 数えない |

操作バーの使い方：「ヒント」は動かす駒を点線で示します。「答え」は定跡の手を指して進めます（ミス1回に数えます）。「戻る」で自分の手の前まで戻れます。

設定タブでは、相手の応手を「分岐を自分で選ぶ」「おまかせ」から選べます。おまかせでは、まだクリアしていない変化が優先して出ます。

## 腕試しモード

学んだ定跡が身についたかを確かめるモードです。稽古と違い、先手・後手も相手の変化もランダムです。

- 先手なら先手中飛車と5筋の歩交換の手順から、後手ならゴキゲン中飛車から出題されます。
- 相手は分岐点で定跡の変化をランダムに選びます。3割ほどの確率で、AIが選んだ定跡にない有力手（AI変化）も指してきます。
- AI変化に入った後は、AIの推奨手との評価値の差が50点以内なら正解です。
- ヒントは使えません。相手の手の解説も伏せられ、対局が終わってから「解説」で読めます。

1局終わると、一発で正解した手の割合と、間違えた局面（「◯手目 ▲◯◯」）が表示されます。「もう一局」で、先手・後手を決め直して次の対局に進みます。通算の局数と満点の数も記録されます。

## 振返りモード

実戦のKIF棋譜を読み込むと、定跡を外れた1手と、そのときの正しい指し方がわかります。それ以降の手は判定しません。

### 読み込み方

1. 画面上の「振返り」を選ぶ。
2. KIF棋譜を貼り付けるか、ファイル（.kif／.kifu）を選ぶ。Shift\_JISのファイルも読める。
3. 自分がどちらかを選ぶ。「自動」なら、飛車を5筋に振った側を自分と判定する。
4. 「この棋譜を振り返る」を押す。

将棋ウォーズや将棋倶楽部24などの棋譜をKIF形式で書き出して使えます。対応しているのは、各手に移動元（「(77)」など）が書かれた平手の棋譜です。

### 結果の読み方

| 外れ方 | 表示されること | 盤の表示 | 再生ボタン |
| --- | --- | --- | --- |
| 自分が外した | 外れた手、正しい定跡の手とその解説、AI評価値の差 | 外れる直前の局面。実際の手は赤、定跡手は緑の矢印 | 正しい定跡の続き（最大10手） |
| 相手が外した | 相手の外れた手、中飛車側の最善の応手と読み筋、実戦でその手を指せたか | 外れた直後の局面。最善の応手は緑の矢印 | 最善の応手の読み筋 |
| 最後まで定跡どおり | そのことだけ | 最後の局面 | なし |

再生中は▶◀で1手ずつ動かし、「外れた局面に戻る」で元に戻ります。「棋譜」タブでは、定跡どおりだった手に✓が付きます。

相手が外れた局面の最善手は、定跡の各局面で相手が指しそうな有力手（1局面あたり上位8手、合1110通り）について事前に計算してあります。この範囲外の珍しい手では、駒得できる手があるときだけ簡易解析で示し、ないときはその旨を表示します。

## AI評価値の見方

評価値は、将棋エンジン「やねうら王」と評価関数「水匠5」で、収録した全324局面を深さ20まで事前に解析した数字です。

- 評価値バーは先手から見た数字です。プラスなら先手、マイナスなら後手が有利です。
- 説明エリアの「AI評価（あなたから見て）」は、自分の側から見た数字です。
- AIは居飛車を好む傾向があり、中飛車側は序盤から数十〜200点ほどマイナスに出ます。初手から▲2六歩のような居飛車の手を最善と示すこともあります。
- 大事なのは定跡手との差です。差が50点以内なら十分に指せる手、300点を超えると形勢を損ねる手の目安です。

| 評価値の大きさ | 形勢の表示 |
| --- | --- |
| 200点未満 | 互角 |
| 200〜599点 | やや有利 |
| 600〜1499点 | 有利 |
| 1500〜2999点 | 優勢 |
| 3000点以上 | 勝勢 |

## 注意点と制限

- **評価値は事前計算**：ページ内でAIが読んでいるわけではありません。収録していない局面では、数手先までの駒の損得だけを見る簡易解析に切り替わります。
- **AI変化の解説**：腕試しのAI変化は手書きの解説がなく、評価値と読み筋だけを表示します。約2手応じたところで終局します。
- **振り返りの範囲**：定跡を外れた1手だけを判定します。その後の中盤・終盤を詳しく見たい対局は、KIFをClaudeのチャットに送れば水匠で解析できます。
- **記録の保存先**：クリア記録と腕試しの成績は、使っているブラウザにだけ保存されます。プライベートモードや履歴の削除で消えます。
- **PC版の機能**：PC版には腕試しと振り返りがありません。
- **共有**：公開中のページは自分だけが開けます。他の人に使ってもらうときは、ページの共有メニューから共有するか、HTMLファイルを渡してください。

# Toshiki17

Claude Code を使って、学びを助けるアプリを作っています。

## 作っているもの

| アプリ | 内容 | 状況 |
| --- | --- | --- |
| [中飛車道場](https://github.com/Toshiki17/NakabishaDOJO) | 中飛車の定跡を自分で指して身につける将棋学習アプリ（iPhone） | App Store 公開準備中 |
| News Lens | ニュース記事の URL を貼ると、要点・背景・用語カード・理解度クイズを作る学生向けのニュース学習ツール（Web） | 開発中 |
| 読書支援ツール（仮） | 新書などを読むときに、難しい箇所の理解、記憶の定着、関連する時事ニュースとのつながりを助けるツール | 企画中 |
